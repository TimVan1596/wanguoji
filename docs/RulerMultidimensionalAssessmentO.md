# v0.99931o 君主多维治绩与历史评价重构

## 目标与边界

本版整理历代君主的史评、史家曰和王室人物卡片。继续使用既有 `RulerHistoricalEvidence`、`politicalFacts`、`RulerChronicle` 与 `WorldHistory`，所有人物评价均为派生结果，不写回权威历史。

APP_VERSION 为 `v0.99931o`，package 为 `0.99.146`，WorldSave 保持 V14。未改存档 Schema、历史事件、模拟规则、玩法概率、RNG、死亡/继承规则及庙号谥号授予算法。

## 现有证据审计

| 维度 | 可用事实 | 归因边界 |
| --- | --- | --- |
| 政治身份 | 创始与正式建国、称帝、统一、复国、异姓篡朝、宗室废立、末代/终结、纳土与合邦等现有身份事实 | 篡朝与废立说明政治身份，不自动代表治绩或失德；关系必须由人物ID和宗谱证据支持 |
| 军事及国势 | 任期快照中的疆域/城市/人口/稳定度；失城、失都、迁都、分裂；`city-captured`、`capital-fallen`；正式政权灭亡、残部解散、流亡 | 快照表示任期结果，不证明君主个人因果。本人攻城要求事件有其 `rulerId`。都城身份按事件月 `wasCapital`，不按地图初始都城推定。失城记录次数与净城市变化是不同指标 |
| 外交及继统 | 有双方签署人和势力ID的停战、互不侵犯、战略同盟；续约事件；实际在任继承候选死亡；即/离位时间和方式 | 签约不能推断外交成功；续约不算首次独立签约；继承候选死亡不等于正式储君死亡 |
| 生涯与结局 | 即位、任期快照、废位、合邦/纳土退位、政治终结、自然死亡、战死、被俘处死、废位后续生存及其后死亡 | 任期结束、政治终结和生命死亡分别处理；被废月不是死亡月，只有真实死亡才适用身后称号 |

独立战争事件依其 canonical ID 分别保留。军事演进类摘要使用 `historyGroupId` 关联同次攻城与国家终局，避免把攻克末城和相应终局写成两份个人功绩；正式灭亡、残部解散和政权流亡的语义仍分别保留。没有直接君主归属时只陈述任内国家结果。

## 评价组织与展示

人物史评继续沿用已有身份与治绩评语，并在同一派生结果中加入可核实事件维度。疆域变化和城市数量方向相反时，直接并列起讫数值，避免只给单向结论；不会把多次失城事件数当作净城市变化。本人攻城、当月都城攻陷、任内国家终局和外交签署使用不同措辞。

史家曰分别处理政治身份、任内结果和结局：被废君主能体现废位后仍生存及后来的真实死亡；废立夺位者的后续国势和实际死亡结局不会被身份句遮住。评价不把失地推成废立动机，不从签约推断外交收益，不因战死抹去此前治绩。相同世界与月份的结果保持确定。

王室人物卡片现将“王位结局”和“生命结局”分开展示；已确认的废立即位不再重复显示同一句“继位背景”。原有亲属关系、即位方式、离位方式、死亡事实均保留。

## 庙号与谥号审计（本版只读）

`PosthumousRules.ts` 及其依赖的 `RulerLegacyEvidence` 已使用正式建国、称帝、统一、复国、疆域/城市扩张、君主个人夺城数、长期稳定、战死及国难等数据。军事依据目前以 `citiesCapturedPersonally` 和统一成果作为粗粒度证据；尚未专门区分事件当月真实敌都与普通城市，也未将“攻克最后据点”“正式国家灭亡”“残部解散”“政权流亡”作为各自独立的称号语义。稳定统治可以加分，但已有 eligibility、任期和局势阈值，并非单凭多年稳定即足以授予所有称号。

篡朝者、废立夺位者与被废者的政治身份尚未成为称号算法的独立评分维度；继承候选死亡、真实失都、协议签署及其结果也没有足够可靠且专门的授号映射。现有“康”“威”“愍”等历史谥号语义丰富，当前数值规则只能近似映射部分治绩与结局，不能视为对传统史义的完整还原。未来如校准，须另立主题和验证 Gate；本版不改任何已授称号或算法。

## 测试与限制

新增的集成回归使用真实 `WorldHistoryStore.addCityCaptured()` 和 `addCapitalFallen()` 构造 canonical 生产格式事件，再贯通人物事件归属和史评派生。验证了只有带本人 ID 的攻城才归为个人行动、事件月都城标记的使用、匿名攻击者排除、疆域增加而城市减少的并列呈现，以及没有同组直接行动时不把国家终局称为个人功绩。既有史评、继承候选与废立证据测试继续保留。

项目当前工作区未提供用户所述 V14 旧档，因此李承澄、李明昭、叶璋及具体军事人物没有硬编码姓名或固定文案。本版不会修改 canonical 事件。自动测试和构建可验证代码路径；页面文字换行、人物样本实际史评、政治宗谱、历史卷轴和 Save/Load 后视觉一致性仍需用户人工 Chrome/Electron 检查。
