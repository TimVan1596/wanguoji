## 2. 推荐决定

## 3. 三种历史维度与B1口径问题

| 维度 | 真实来源 | 能说明什么 | 不能说明什么 |
| --- | --- | --- | --- |
| 国家历史记忆 | 稳定factionId、stateFoundedMonth、实际在国区间、City.history、旧都、主权沿革、复国事件 | 同一国家实际存在和统治过哪些地方 | 居民认同、兵力、对某家族的支持 |
| 当前王统资历 | 本国houseEpochs及其起止月、真实人物和合法继统资格 | 当前家族何时取得王统，以及实际在国统治多久 | 前王统的全部家族资历、流亡期实际治理 |
| 现实恢复能力 | WorldRemnants、WorldExiles、hasClaimantAtMonth、当前城市状态 | 现有残部、正合法性、真实继统主体和地方机会 | 历史声望可以代替现实人口或君主 |

国家改号沿用同一factionId和nameHistory。不同factionId即使国号相同，也不合并历史；同姓的新epoch也不能仅凭姓氏拼接前王统。

### 已确认的纯派生问题

`deriveFactionRestorationHistoricalProfile()`目前将国家年资取为 `cumulativeActiveYears + 当前ACTIVE区间`，其中Year实际为月。该值排除了流亡月，但生命周期从势力产生开始累计，函数又未读取stateFoundedMonth，因此可能包含正式建国前的临时政权在国月份。

当前王统年资则由 `worldMonth - epoch.startMonth` 得出。它包括流亡期，也包括同一epoch内多次流亡的空档。B1“新epoch不继承旧epoch”的边界成立，但该数值只能解释为王统延续时长，不能直接称为实际在国统治时长。现有测试只验证epoch起点差异，尚未覆盖这种空档。

B1现有两项权重各自小于0.15，因此profile派生的合计倍率在有限年资下小于1.30；传入cap=1.35并不使该profile能够达到1.35。离线风险工具直接传入1.35的测试，只证明封顶计算正确，不能证明真实profile产生过这个倍率。1.15、1.275也仍是研究点位，并未接入生产。

例如：新王统开始后在国15年，再流亡5年，当前函数会得到20年；不能按20年实际统治计权。另一个王统在国200年、流亡30年、复国20年，其实际在国资历为220年，连续王统时长为250年。

### Stage B推荐的正确派生

保留现有profile体系，明确派生以下口径，不建立新人物或历史数据库：

```ts
interface RestorationTenureEvidence {
  factionId: string;
  asOfMonth: number;
  stateFoundedMonth: number;
  stateInStateMonths: number;
  currentHouseEpochStartMonth: number;
  currentHouseInStateMonths: number;
  currentHouseContinuityMonths: number; // 可含流亡，仅作身份说明
  complete: boolean;
}
```

利用 `WorldHistory.getEventsForFaction()` 的既有索引，按真实月份和canonical同月顺序读取本国 `faction-exiled`（targetFactionId）与 `faction-restored`（actorFactionId），重建ACTIVE区间。与stateFoundedMonth、epoch区间相交，分别累计国家和当前王统的正式在国月份。复用 `RulerTenureEvidence.ts` 已有的生命周期事件身份核验、事件组去重及区间裁剪思路，不直接累加各君主任期，以免重复或混入流亡。

B1现有profile还要求具体城市的basis/heldMonths。应从该体系抽出共用的年资派生核心，再由城市profile适配器加入真实城市依据；资源衰减修正直接使用共用年资，不能为了调用旧接口而伪填“旧都”或持有月份。

全生命周期区间应与Team累计在国月数、当前状态、lastExiledYear、restorationYears交叉校验；正式国家年资裁去建国前月份。家族项裁去epoch开始前及所有流亡区间。正常同宗继承、宗室废立不重置epoch；异姓篡朝后的新epoch仅累计自身区间。

区间统一按半开区间计算，epoch现有包含式endMonth转换为右端点endMonth+1。`getEventsForFaction()`按月份倒序返回，当前相同月份的记录仍保留追加顺序；应稳定地按月份升序处理，不能简单反转整个数组或按事件ID重排同月事件。需要以同月流亡→复国→再流亡及保存恢复测试锁定该合同。

不完整、未来、矛盾或跨国家的证据使相应历史加成归零，并显示证据不足；不能以当前月份减起始月份兜底。仅有 `cumulativeActiveYears` 和epoch起点不足以精确拆分多次流亡，不能因此复制前王统总年资。

City.history的旧都/持有资格目前属于国家实体，不属于某一王室。其heldMonths累计该faction的真实占有区间，尚未裁去正式建国前的占有月份；只有formalCapitalRecorded要求首都记录发生于正式建国后。因此“有正式旧都记录且累计持有120月”不等于“正式建国后在该城建都120月”。前王统掌握某城的数百个月可以证明该国家的旧地联系，不能写成新家族统治该城数百年。当前方案保留既有旧地门槛，不顺手改写该资格，也不新造地方王室认同。

## 4. 真实调用链与机会漏斗

生产月界中，`AutoSimulator.advance()`先运行WorldEventSystem（其中含年度城市复国检查），再更新Dynasty真实寿命/继统，随后更新WorldExiles资源。实际移动、战斗接触与城市攻陷还依赖Core固定步进及Phaser/逻辑占领路径，单独推进年度复国检查不能产生完整自然战争。

| 阶段 | 当前权威路径及主要限制 | 需要分别观测的数量 |
| --- | --- | --- |
| 1. 失去最后城市 | Core终局处理、Team.markExiled、WorldRemnants、WorldExiles.start | 新流亡政权数、起始真实残部和合法性 |
| 2. 流亡合法性 | 初始70～90；每12月按残部和帝国修正衰减 | 正值月份、首次归零转变 |
| 3. 残部存续 | 每18月一次45%衰减检查 | 检查数、命中数、首次残部归零转变 |
| 4. 真实继统主体 | Dynasty.hasClaimantAtMonth | 有主体的流亡月份、最后主体消失转变 |
| 5. 地方现实机会 | 城市忠诚、破坏、近期易手/占领方稳定、保护期和冷却 | 城市检查、各前置阻断 |
| 6. 历史及完整资格 | 正式旧都持有≥120月或长期持有≥360月；EXILED、残部>0、合法性>0、可继统 | 历史候选、各资源阻断、完整合格 |
| 7. 城市实际抽签 | 多候选竞争同一次draw，总风险为最高单项而非相加 | 真正draw数、有效总风险之和 |
| 8. 抽中 | selectRestorationOpportunity或原建城者路径 | 未命中、命中及选中来源 |
| 9. 执行恢复 | FactionRegistry.restoreFaction→City.revoltTo→实际人口生成→历史 | 执行尝试、失败、成功、实际生成数 |
| 10. 恢复后生存 | 原城市、战争、人口和政治生命周期继续运行 | 12/60月仍在国、再次流亡、终结、随访不足 |

残部、合法性、继统者是相互独立的硬门槛。最后继统者死亡后，即使有残部也不能复国；残部为0时，即使合法性很高也不能复国。双零政治终结仍不以宗室是否存活为条件，不把政治终结写成人物死亡。

更早的失国入口同样可能阻断机会：`Core.handleFactionExtinction()`先将高忠诚的既有User计入残部，其他人口按原规则投降或离散；只有存在残部且君主逃脱或真实后继能够延续时，才进入EXILED。否则直接进入终结。方案A只作用于已经合法进入流亡的真实残部，不能挽回“从未形成流亡主体”的国家，也不修改逃脱、被俘或继承规则。

B1的 `hasClaimantAtMonth()`已解决“当月到达自然死亡月份但状态更新尚未执行”的资格问题。本版设计继续复用，不调整自然死亡日期或整个年界顺序。另需校验无月份的UI资格预览与传月份的实际执行口径，诊断不能把预览当成真实合格。

当前诊断的“执行尝试”发生在抽中之后，不等于真实随机draw。城市条件过滤先于历史资格检查，现有“残部耗尽”等阻断只覆盖到达该段的候选，不能推成全部流亡国家的瓶颈比例。现有诊断没有完整资源归零漏斗、有效概率和及12/60月随访，无法给出自然世界主阻断的排名。

## 5. 残部与合法性的实际衰减

当前每次残部衰减命中后：`N' = max(0, N - max(1, floor(0.2N)))`。每18月以45%命中；没有国家年资或王统年资项。

- 1名残部只需1次命中便归零；在没有恢复或新增输入时，归零等待期望为40个月，存续中位数36个月。
- 5名残部按5→4→3→2→1→0，需要5次命中；仅就该过程，归零等待期望为200个月。
- 恰好12名按12→10→8→7→6→5→4→3→2→1→0，需要10次命中；对应期望400个月。

上述是条件数学结果，不包含继统者死亡、恢复、战争等世界行为，不能解释为政权自然寿命。

现有残部是从真实失国人口转出的匿名人数池，原User运行时对象已移除，未保存逐个残部人物的生命史。降低该池的衰减概率表示有限的流亡人口存续修正，不能宣称原来某个具体User获得了延寿。恢复时生成运行时成员、消费人数池，事件只记录实际生成数；国家/王统身份可连续，普通残部个人身份没有因此连续。

“1名残部响应”也不必等于恢复后的Team.users总数为1：`City.revoltTo()`调用 `Dynasty.markRestored()`，会为已存在、达到出战年龄的真实在位君主重新绑定一个RULER User；随后再尝试生成残部对应的NORMAL User。正常成功时可以是1名残部成员加1个君主单位，未成年君主则没有该地图单位。它没有生成新的王室人物，统计应分开记录两种来源。现有restoreFaction在城市接管成功后会返回成功，即使spawnMembers部分或全部失败；调用方仍消费请求的残部数量。Stage B必须测试并记录实际生成数与RULER_LIFECYCLE变化，不能只凭返回true判断现实人口充分，亦不能把这个潜在执行边界归咎于抽签概率。本阶段未证明自然运行中出现过该失败情况。

每年合法性扣除：`max(1, baseDecay - min(3, floor(N/4)))`，王国baseDecay=4，帝国baseDecay=2.2。若残部固定不变，初始70～90的归零年数如下；现实中残部会下降，缓冲随之减少：

| 固定残部 | 王国每年扣除 / 归零年度检查数 | 帝国每年扣除 / 归零年度检查数 |
| --- | --- | --- |
| 1 | 4 / 18～23 | 2.2 / 32～41 |
| 5 | 3 / 24～30 | 1.2 / 59～75 |
| ≥12 | 1 / 70～90 | 1 / 70～90 |

当残部从12降至10、再降至7、3时，王国年扣除依次从1升至2、3、4；帝国从1升至1.2、2.2。流亡5年后的初始扣除率不能直接外推50年。

本阶段实际执行了只读的离散概率分布计算：初始合法性80，每月按上述生产公式顺序（同月先合法性、后残部）演算，保留全部随机衰减分支；不推进城市、人物寿命、复国、外交或战争。得到：

| 起始残部 | 5年仍有残部 | 10年仍有残部 | 20年仍有残部 | 王国合法性期望：5/10/20年 |
| --- | ---: | ---: | ---: | --- |
| 1 | 16.6375% | 2.7681% | 0.0421% | 60 / 40 / 0 |
| 5 | 100% | 93.0802% | 22.7948% | 64.372 / 46.014 / 6.423 |
| 12 | 100% | 100% | 97.9658% | 72.478 / 61.159 / 31.473 |

同样的帝国样本，20年合法性期望分别为36、42.423、56.739；残部存续概率完全相同，因为帝国修正目前仅保护合法性。合法性80、1名残部的王国20年后，即使罕有残部仍存，合法性也已为0，因此完整资源资格为0。

这证明“仅延长合法性”无法保护残部，亦证明残部数量不同会显著改变资源机会窗口。它不能证明自然世界最常见的起始残部是1人，也不能证明城市机会是次要瓶颈；这两项仍需真实运行数据。

## 6. 三种方案比较

| 方案 | 游戏性、可达性与因果边界 | 人口、长局及存档影响 | 首版判断 |
| --- | --- | --- | --- |
| A. 有限残部存续保护 | 让真实长治国家/王统已有的残部较不易在短窗口内耗尽；历史年资作为有限玩法修正，不声称存在未记录的组织或民意 | 不增加人口；降低部分衰减命中率会延后双零终结、增加流亡国家月数。现有计时与资源字段足够，易测试 | **推荐首版研究并校准** |
| B. 旧地真实响应 | 能在旧残部归零后，以旧地现存人口转属形成新的真实恢复能力；必须新定义响应行为、位置/身份资格和人口转移事务 | 要防止消耗占领国人口后又spawn同数人口。源User、logicalUnit、MilitaryPerson转属、城市终局和事件需同步；资格频率未知，成本较高 | 暂缓，另作明确行为合同 |
| C. 仅加历史倍率 | 已有合格机会时可增加条件期望；没有残部、继统者或城市机会时收益为0，风险已封顶时也无效果 | 不改变资源；B1工具已存在，但没有自然机会流证明生产倍率。无Schema需要，成本低 | 保留分析，不单独落地 |

不建议把A、B、C同时投入首版。A能够直接处理已确认的单残部快速归零机制，且其效果可以与城市机会频率、合法性和继统者存续分别对账。B改变现实人口来源，不能视为A的小补丁；C不能替代资源瓶颈分析。

## 7. 推荐首版的参数与边界

先修正历史profile，取流亡开始月为证据截止月；该次流亡不会因时间继续流逝而增加历史统治资历。用B1已有的饱和形状定义实验分数：

```text
S = 国家正式实际在国月数 / (国家正式实际在国月数 + 3600)
D = 当前epoch正式实际在国月数 / (当前epoch正式实际在国月数 + 3600)
H = 0.25 × S + 0.75 × D                    // 0≤H<1
W(t) = max(0, 1 - 流亡月数/240)           // 最多保护20年，逐步退出
p_decay(t) = 0.45 × (1 - a × H × W(t))
```

国家与王统使用同一饱和曲线但各有来源；当前家族权重较高，国家记忆仍留有限份额。这是待验证的游戏规则假设，不是测得的民众支持率。

实验组：基线a=0；轻度a=0.25；中度a=0.50。任意历史下命中概率仍至少22.5%，20年后回到45%；首版建议以轻度作为候选，**中度只作对照，不能未经批准进入生产**。若Stage B真实机会数据不支持收益，维持基线，不继续加码。

| 历史样本，流亡开始时 | S | D | H | 初始轻度 / 中度衰减概率 |
| --- | ---: | ---: | ---: | --- |
| 国家在国500年，同王统500年 | 0.625 | 0.625 | 0.625 | 37.9688% / 30.9375% |
| 国家在国500年，新王统20年 | 0.625 | 0.0625 | 0.203125 | 42.7148% / 40.4297% |
| 国家、王统均在国20年 | 0.0625 | 0.0625 | 0.0625 | 44.2969% / 43.5938% |

这些初始概率是公式起点；第一次实际检查在18个月时，W已下降，不能当成整个流亡期的固定概率。上节同一资源分布计算中，500年同王统、1残部、合法性80的王国：轻度5/10年仍有残部约22.6703%/4.7496%，中度约30.0058%/7.7862%，基线为16.6375%/2.7681%。20年时三组合法性均归零，完整资源资格仍为0。

首版明确限制：

- 不给残部设永久最低1人，不补充已经归零的残部，不因历史年资生成User、军队或继承人。
- 不改变18月检查周期或命中后的衰减数量；每次既有检查仍最多消费原来一次WorldRandom抽签，不增加诊断抽签。
- 不改合法性70～90初值、原年度衰减、君主/继承者寿命、双零政治终结条件。
- 不让历史跨越残部>0、合法性>0、真实存活继统者、旧地和当地政治条件的硬门槛。
- 同一王统多次复国后再次流亡，用新的流亡开始月和已有真实在国积累重新派生；保护期重启可能形成循环，必须单列复国次数和再次流亡率，不能承诺循环风险已解决。

## 8. 旧地真实响应的后续边界

首版残部归零后不新增响应来源。若以后批准B，最低可成立的机制应是：在真实旧城发生符合规则的政治动乱时，选择事前存在、当前存活、所属明确且权威位置确在该城市范围的普通User及其逻辑单位，在一次成功政治转换中转属仍有真实继统者的旧国家。低忠诚只表示当地现状，不证明其先前忠于旧朝。

不能先给WorldRemnants加人数再调用现有spawnMembers。现有恢复函数根据残部重新生成运行时成员；新路径必须直接转移既存User，守恒核对“原国家−N、恢复国家+N、世界总量不变”，并处理旧军职/编组解绑、源国家最后城市、城市归属、王室和唯一事件组。实际转属成功数才能写入事件，不能沿用“N名旧国残部响应”的旧叙述。

即时响应事务未必需要V16：成功后的所属、单位、城市和历史结果原则上可由现有V15保存。但若要先形成待命响应组织、持久的地方王统认同、参与者资格/冷却或流亡组织资源，就需要新的authoritative状态，应另提V16设计Gate。当前没有这些身份，不应从坐标或低忠诚倒推。

## 9. Stage B实验、诊断与性能合同

### 先验证资格暴露，再评价自然成功

保留生产全部战争、城市、人口、外交、王室与寿命流程。按真实流亡事件分组：在国不足20年、20～100年、100～300年、300年以上；另列“国家≥300年、当前王统≤20年”。分组是观察口径，不是硬加成门槛。

对配对初始seed/快照观察基线、轻度、中度。先在同一基线机会流上离线重算资源存续和条件风险，再运行真实对照。改变衰减命中后，未来单位、战争及RNG调用可能分叉，分叉后的整段历史差异不能视为相同事件的直接因果对照。

必须记录：

- 每次流亡起始残部、合法性、国家与王统实际在国年资；流亡总月份。
- 残部衰减检查/命中、残部首次归零、合法性首次归零、最后继统者消失、双零终结。归零是每流亡事件的状态转变，不能按每月重复计数。
- 旧都/长期地候选、城市条件阻断、残部/合法性/继统者阻断、完整资格；候选以城市×国家×年度为单位，可重复。
- 真实城市draw、具有合格历史候选的draw、有效总触发概率之和、随机未命中、命中后执行尝试、失败和真实成功。
- 每次复国实际生成数、12/60个月仍在国、再度流亡、在国存续期和最终终结。观察不足12/60月分别标为随访不足。
- 当前流亡国家数、累计流亡月、复国循环和活跃国家数，防止只看恢复次数而忽略幽灵政权积累。

现有生产Core/Phaser中确有完整自然运行路径；仓库没有已完成的完整多种子runner。B1的年度复国夹具关闭真实战争、人口、寿命和城市演化；现有保存/生命周期测试也不能代替自然平衡实验。Stage A本次没有补造runner、没有运行自然多种子长局。

Stage B可先补充实际运行会话的结构统计，配合有限真实Core固定步进测试能力；若完整runner仍无法运行，必须保留这个证据限制。不能用受控资源公式或强制成功抽签批准自然复国率，也不要求用户反复运行几千年刷样本。

### 低开销与确定性

历史profile按流亡事件、证据截止月在年界/18月资源检查时按需派生；同次年度检查内每国只算一次，不逐城重复扫描。优先复用WorldHistory的势力索引。运行时缓存必须在世界reset/import时清空，并随相关生命周期/epoch事件失效；缓存本身不能影响随机数或存档结果。

会话诊断采用固定计数和有界随访记录；读取重置。存档完整历史恢复次数来自canonical事件，不能与会话计数混用。全部原有城市主权历史和王室谱系继续保留。
