## 围城损耗审计

真实月度调用链为 `AutoSimulator.advance()` → 每支正式势力的 `City.updateDefense()` → `City.updateSiege()`。单位接触由 Phaser `Block.setTeam()` 或逻辑模拟 `applyLogicalOccupation()` 注册到城市；逻辑路径用 unitId、cityId、worldMonth 防止同一单位同月重复注册。每座城市每月汇总并清空围城接触，只选择主要攻击势力；`shouldApplySiegeDamage()` 单独检查该城上次伤害月份。首个有效伤害月可造成伤害，之后至少间隔2个月。每次实际伤害降低1点基础城防（仍受既有势力效果及余数规则影响），并调用守方 `removeOneUser()` 一次。

- 同城同月有多个单位或多次物理接触时，仍只进入一次城市月度更新；伤害间隔再阻止过密伤害。因此没有发现重复扣人口的程序路径。
- 两座或更多城市各自到达本城伤害月份时，可以在同一世界月各移除一名守方人口。每座城有独立的伤害月份，这是现行并行围城规则，不是同一人口被重复删除。
- `removeOneUser()` 从整个国家 User 集合按集合顺序寻找可成功销毁者，并不核验其当前地图位置。它可能移除已任命的指挥官或其他不在该城附近的人。`SIEGE_LOSS`证明人口损失由围城伤害路径触发，不证明死者亲自守城、死于某座城或参与了该次围攻。
- 人口变化审计现在将同月不同触发城市的 `SIEGE_LOSS` 分开记录城市ID，避免合并成无法对账的一条记录；该上下文描述造成损失的城市，不是死者位置。权威死亡原因代码仍原样保存在人物记录中，界面同时显示友好说明和原代码。
- 以用户提供的郢东、大梁东记录看，2个月左右的间隔符合单城伤害节奏；连续月份损失可能来自不同城市各自到期。仅凭这几行不能确认每一条具体城市来源，需在新诊断中查看触发城市ID。

## 军令目标与实际执行

`MilitaryCommandRegistry.update()` 每月刷新命令；原实现对合法敌城按 `city.id` 字典序选首个目标，不比较距离，也没有路径可达性判断。命令实际作用于 Phaser 固定步进或 `LogicalSimulationCore` 的既有单位速度方向，之后仍由普通移动、外交准入、城市接触、围城伤害和攻陷规则完成行动。没有命令的单位仍走原移动规则。命令没有瞬移、攻城加成或直接改城主路径。

本轮将新目标选择改为：编组现存成员位置的中心至合法敌城的直线距离最近；距离相同按稳定 `cityId`。这是距离启发式，不是道路/地形路径寻优，仍可能因地图边界或局部运动规则无法抵达。已有目标在仍属合法敌城且外交允许时保持不变；目标易主、失效或外交不再允许时清除并重新选取。

新增运行会话累计诊断（不进入 V15，不消费 RNG）：

- `orders`：成功分配目标的次数；
- `unitsSteered`：单位速度向量被命令调整的固定步进次数，不是唯一单位数；
- `targetCityArrivals`：编组首次在本会话对其当前目标城产生有效接触的次数；
- `commandedSiegeContacts`：有效编组归属的实际城市围城接触次数；
- `captures`：由现有 canonical 城市攻陷/收复事件核验并归属编组的次数；
- `invalidatedTargets`：既有目标因易主、城市失效或外交限制而需要清除的次数；
- `staleOrderChecks`：命令持续至少120个月后，每再过120个月检查一次；若最近成员仍距目标超过8个地图格，且相比上次检查未接近至少1格，则计一次。该值是远距且无明显接近的诊断，不自动取消或改写命令。

以上均为全世界本次运行口径；读档后会话累计重新开始。`MilitaryCommandRegistry.exportState()` 仍只包含 V15 权威人物、编组、命令、序列与月份状态。会话诊断不影响导出、恢复或随机流。

自动测试证明生产目标刷新、逻辑单位转向与移动、抵达真实城市接触及贡献归属路径可以相连；受控测试不等于自然世界攻陷率或将领战功频率。当前没有覆盖完整 Phaser/Core、战争、人口、外交及政治演化的多种子自然长跑运行器，因此本轮不声称 V15 已导致人口骤降，也没有证据将用户观察的将领死亡高频归因于新军令。

## 人物界面

- 军政人物按现役指挥官、已离任、已故排序；状态内按最近任职/死亡月份从近到远，再按稳定 `personId` 排序。旧人物保留。
- 面板分开显示本国现役指挥官数、活动编组数、历史任职人物数，以及“全世界本次运行累计诊断”；不再把全世界会话数字误称成本国数据。
- 活动命令提供“定位部队”和“查看目标城”，并明确“军令自动执行；以下操作只定位地图”。目标城市定位只改变镜头中心并高亮城市，保留当前缩放，不复用打开城市详情的通用定位方法。
- 已故人物显示“享年”；`SIEGE_LOSS`显示“围城战损（SIEGE_LOSS）”，不写守城战死、死亡地点或战斗经过。现有人口姓名（如“燕-009”）和永久 `personId` 保持不变；本轮不为叙事改名。
