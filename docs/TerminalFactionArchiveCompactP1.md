# v0.99931p1 终结势力档案紧凑展示

本版目标是改善约 350px 右侧面板中的【天下势力→终结】档案可读性。APP_VERSION 为 `v0.99931p1`，package 为 `0.99.148`，WorldSave 保持 V14。

## 实现

- 终结分页使用独立双行卡片，不再套用六列布局。首行显示势力颜色标识、历史档案名称和完整终结年月；长名称单行省略，完整名称保留在原生标题提示中。
- 次行显示真实终结类型、既有累计在国时长和初建年月。终结日期继续使用 `extinctionYear` 或 `terminationMonth` 的既有月份值；缺失时显示“—”。
- 终结卡片不显示城市数，也不显示重复的“已终结”状态。复国次数为零时默认省略；有复国记录时显示次数；按复国次数排序时即使为零也会显示实际计数。
- 终结列表点击仍以原 `team.name`（稳定 factionId）打开详情。全部、存续、流亡继续使用原六列布局与排序行为。排序函数、终结状态、玩法、canonical历史及 V14 Schema 均未修改。
