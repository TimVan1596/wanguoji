## 真实根因与范围

1. 新世界由 Core 的正常新局路径进入 AutoSimulator.startWorld；原七国统一 initializeFaction，随后 ensureActiveHeir(..., true)。一城/低稳定的 bootstrapOnly 初次只生成一名直系子女，之后不填满候选上限，所以几乎都是一条父子线。
2. candidateCap 是合法候选池上限，不是整个宗室人数目标：临时势力2、王国4、帝国6。家族成员、候选、指定储君是三个概念。
3. 兄弟须有实际共同父辈，叔侄和堂亲须有可追溯祖先。旧纯关系查询可凭同一个缺失的 parentId 字符串判为兄弟；本版要求祖先记录实际存在，合法亲属的继承优先级不变。
4. createHeir 的亲子生年派生失败时，旧逻辑仍可补造成人并保留 parentId。现明确拒绝缺失/过年轻父母的非法创建；正常可生成路径保留既有寿限、命名及继位规则。
5. 非候选 kin 已有自然死亡回收路径，本版复用，不另设生育或死亡模拟。
6. Hydrator 使用已有人物状态 import，不调用 startWorld；旧 V13 读取不补人、不新增历史、不重抽随机数。

## 保守初始模型

仅正常新世界恰好七个 INITIAL 势力启用新模型，仍通过真正的 DynastyRegistry 创建人物；后续义军、叛军、复国与普通 initializeFaction 默认沿用原路径。

- 创始者仍一人，真实第一代与 FOUNDING epoch 不变。
- 最多新增3名亲属：一名共同父辈、一名兄弟、一名子女。最多4名家庭成员，初始合法候选最多2名，指定储君最多1名。
- 不生成叔侄/堂亲扩张树；已有合法叔侄/堂亲关系规则单独回归。
- 年轻创始者（不足22岁）计划概率：无亲属30%、仅子女25%、仅兄弟35%、子女和兄弟10%。其他年龄：15%、45%、25%、15%。这些是计划分布，最终人数受实际寿限过滤。
- 创始者年龄继续原18～42岁；亲子出生时父辈年龄继续原18～40岁。年轻创始者不会补造成年子女，年长者可有成年子女。
- 共同父辈生年比创始者早18～22年；兄弟在可验证的生育区间内出生，与创始者相差最多4年。
- 共同父辈只以仍活着的 kin 入册，无 accession、reignOrdinal、chronicle、死亡月份和死亡事件；其出现在宗谱根部不等于势力创始或正式开国。
- 所抽寿限已在开局前结束的人物不入册，不把计划寿限变成虚构死亡史。父辈不入册时也不生成无共同父母证据的兄弟。
- 兄弟与子女按现有规则进入候选，直系优先级不变；不保证有储君，不填满既有 candidateCap。父辈不自动成为候选。
- 宗谱已有悬停说明补充真实年龄、未曾承统及父辈身份，保持节点样式、血缘连线、缩放与定位。
