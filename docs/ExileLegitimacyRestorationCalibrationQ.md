# 流亡正统性与旧地复国校准：v0.99931q B1

## 阶段结论

B1完成了同月继统资格正确性修复和纯派生历史资历分析模型；正式复国规则、风险、合法性与残部衰减均未接入新模型。**本轮没有完成真实完整 AutoSimulator/Core 多种子运行器，也没有取得可用于校准自然复国率的长跑数据。** 因此不能据此批准生产加成或声称长期王朝的自然复国率已得到校准。

- 基线版本仍为 APP `v0.99931p1` / package `0.99.148` / WorldSave V14。
- 本轮未改 WorldSave Schema、canonical 历史、正式复国概率、RNG调用、初始合法性、残部衰减或自然寿命。
- 工作范围限于当月资格正确性、只读资历分析和测试；没有创建完整长跑工具。

## 1. 月度路径与同月继统资格

`AutoSimulator.advance()` 每个世界月先调用 `WorldEventSystem.update()`，其内可能进行城市年度复国检查；随后才调用 `DynastyRegistry.update()`，最后才由 `WorldExiles.update()` 衰减流亡资源。因此，某位流亡在位君主或最后继统者在月份 M 到达真实预定死亡月份时，原检查可能先看到其 `status` 仍为 `exiled` / `heir`，并错误判定有继统者。

现在复国年度检查及 `FactionRegistry` 执行入口使用 `DynastyRegistry.hasClaimantAtMonth(factionId, worldMonth)`。该只读检查以 `naturalDeathYear ?? plannedEndYear` 对照传入月份，排除在该月已到自然死亡月份的当前君主和继承候选。它不改人物状态、不写死亡记录、不选择继承人、不消耗随机数，也不调整整个模拟顺序。若另有状态有效且本月尚存的合法候选，仍返回有继统者。

回归覆盖：最后候选在检查月死亡时不会复国；检查本身不提前写死亡；另一位真实生成且存活的继承候选仍使继统资格成立；随后 `DynastyRegistry.update()` 负责写入确切死亡月并执行正常继承。

## 2. 现有证据口径

- 国家连续性来自稳定 `factionId`、正式国家阶段和 Team 的累计实际在国月份。该累计值底层保存为月索引；流亡月不会计入。
- 当前王统连续性来自 `Dynasty.houseEpochs` 中结束月份未定义、起始月份不晚于当前世界月的 epoch。异姓篡朝以新 `USURPATION` epoch 开始，新家族不能继承前 epoch 的家族年资；同一 epoch 内的正常继承和宗室废立不重置年资。
- 旧都/长期统治地资格仍来自完整 `City.history` 与稳定 `factionId`：正式建国后确有首都记录且本国累计占有≥120月，或累计占有≥360月。城市原始首都身份不会被假设为永恒首都。
- 城市忠诚、破坏、易手、占领方稳定度、保护期和冷却仍是独立的当前机会证据。
- 这些记录没有表达地方居民对某王室的认同、军力、流亡组织或政治声望。报告不把历史年资解释为这些资源。

### 纯派生分析模型

新增 `deriveFactionRestorationHistoricalProfile()`，只从 Team 的累计在国月数和当前活动月份，以及 Dynasty 的当前 house epoch 派生国家年资与家族年资；城市依据与 heldMonths由既有经过校验的历史城市规则提供。它不修改实体或存档。

单一历史权重采用饱和函数：`0.15 × months / (months + 3600)`。国家与当前王统分别计权，再相加到 1.00；整体受调用方提供的 cap 限制，缺少有效 epoch 时家族项为0。该函数是实验分析工具，不是经实证校准的民众支持模型，也未进入生产抽签公式。

离线重算工具 `applyRestorationHistoricalMultiplier()`只做 `min(pathCap, baseChance × multiplier)`，默认旧都/长期路径 cap 为9%；战乱旧地可显式传3%。因此基线风险已达到相应 cap 时，倍率没有边际效果。建议后续配对同一观测机会流，报告倍率前后的期望风险；世界因实际成功复国分叉后，不再把后续战争或复国差异当作同一事件流的因果对照。

可比较点位：基线 1.00、轻度代表值1.15（实际再给1.10–1.20区间敏感性）、中度代表值1.275（再给1.20–1.35区间敏感性）。这些仅用于反事实计算，**未获生产授权**。

## 3. 复国真实资源与一人残部

生产硬门槛继续要求正式国家、残部>0、可继统者、正合法性以及城市/历史路径资格。新增年资不绕过任何门槛。原始建城者和其他未采用历史年资的旧路径未被削弱。

现有 `FactionRegistry.restoreFaction()`实际把合格城市交还原 `factionId`，调用城市 `revoltTo()`并重设防御、围城、首都与忠诚状态；随后按残部数量尝试生成成员，事件记成功生成数，恢复Dynasty并清除流亡状态。没有额外保护期。一名残部的案例只能证明一次人口生成与城市所有权转移，不能证明有地方拥戴或足够军力；低防、有限忠诚的城市可以再度失守。初始化复国和后续稳定在国是不同结果。

## 4. 完整多种子运行器审计

当前生产月度规则路径确实在 `AutoSimulator.advance()`，包括 `WorldEventSystem`（复国、分裂、普通叛乱和城建）、外交、PopulationSystem、City防御更新、Dynasty寿命/继承、WorldExiles、FactionSnapshots和WorldHistory。

但真实战争围城接触、单位移动与攻陷不是 `AutoSimulator` 月度函数独立完成：它们由 `Core` 的固定步进路径、Phaser Arcade物理和碰撞回调驱动。真实新世界建立也由 `Core.init()` 创建 Map、Team、City、单位、碰撞器和初始人口。仓库没有现成的无渲染 `Core` 初始化/固定物理步进 multi-seed runner。现有测试的 `HistoricalRestorationExecution.test.ts` mock了 Phaser/Game/Team/Block/User 边界并直接调用年度复国检查；其固定种子对照明确关闭战争、人口演化、寿命和忠诚度演化。它能验证执行链，不是自然运行器。

因此本轮没有声称覆盖完整自然系统，也没有给出每种子流亡月、资源归零、城市合格候选、draw、自然成功和12/60月复国存续率。旧受控夹具的抽签成功数不纳入本轮校准结果。历史诊断的现有UI仍是本次会话口径，读取时重置；不能代表存档全史。

若要继续完成用户批准的实验，最小可行工作是提供可在真实 Phaser `Core` 与 Arcade World 上创建新世界、固定 WorldRandom seed、推进同一 Core 固定模拟步、导出每月结构统计的专用 headless/browser runner。它必须调用产品实际的初始化和固定步进入口；只调用 `AutoSimulator.advance()`不足以测试真实战斗和城市占领。此 runner需要先确认 Phaser headless 模式能否支持项目的 Map/碰撞/单位代码。若不能，须另作实验架构决策，不能用人工模拟替代。

## 5. 目前能与不能得出的结论

| 问题 | 本轮证据 |
| --- | --- |
| 长期国家合法性存续 | 未新增自然长跑；现有衰减实际还受人口每18个月随机衰减影响，静态年限表不能代表自然存续。 |
| 国家长、当前王统短 | 纯派生字段可以区分；国家累计在国月份仍可长，而新 usurpation epoch 家族月数从其真实 startMonth 算起。没有真实机会样本验证结果权重。 |
| 旧都和长期统治机会 | 原门槛仍需要城市忠诚/战乱状态、历史持有和流亡现实资格；当前候选频率未测。 |

## 6. V14、随机数和性能

WorldSave保持V14且没有增添权威字段。历史资历纯派生；不存在旧数据回填。新增月度资格检查是确定性读取，不调用WorldRandom。倍率函数完全未接入生产概率；既有候选风险、9%与3%上限及抽签调用位置不变。此次新增资格检查会让人物在自然死亡月不再错误成为候选，这是必要的边界正确性修复；不改变该人物预定寿命或死亡记录月份。

V14原有序列化结构不变。V14 round-trip、世界尺度性能没有通过新的全长多种子运行测量；报告不宣称本轮已测得长局性能。

## 7. 修改与验证

修改范围：

- `Dynasty.hasClaimantAtMonth()`：只读排除自然死亡月已到的继统者。
- `FactionRegistry.canRestoreFaction()` / `restoreFaction()`：允许自然模拟入口传入判断月份；所有 `WorldEventSystem` 的自然、分裂前和神力恢复入口都传当月，UI诊断兼容原无月份调用。
- `HistoricalRestorationRules.ts`：新增纯派生国家/王统资历档案与保留现有风险上限的离线重算函数。
- `HistoricalRestorationRules.test.ts`、`HistoricalRestorationExecution.test.ts`：分别覆盖国家/王统年资来源、饱和与上限、反事实倍率封顶、同月最后继统者死亡与另一真实候选仍存的业务路径。

APP/package版本未升级，CHANGELOG/ROADMAP未标记正式 q 发布。本报告作为B1中间校准交付；生产倍率保持1.00。
