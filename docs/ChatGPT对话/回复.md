**时间一致性**

靳氏问题的根因得到生产路径验证：**推定生辰早，不代表居民和父子关系当时已经存在。**成年居民首次入籍时才建立真实 User 与家族登记，不能拿后来登记的儿子改写过去的袭爵结果。

**正式发布多期爵位再兴**

同一原国、同一王统内，一族同一时点只有一条有效主承袭链：

- 旧期终止后，在世、在籍、资格有效的后代，可凭独立、有效且未使用过的新授爵权源开立后一期。
- 现持爵者本人获得更高新爵，可以开新期替代旧主链；较低或同级新爵不自动替代。
- 每期独立记录权源、持有人、起始事件、承袭和终止；旧记录不覆盖。
- 继续公→侯→伯→子→男世降，不传军职、部队、军功或食邑。

真实 Core 已验证“旧爵断袭→后来入籍→正常任校尉→本人立功封伯→第二期→合法世降”，也验证了写入失败后的完整状态与 RNG 回滚。
