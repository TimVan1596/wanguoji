## 现有事实能支持什么

HouseEpoch 持久化 houseName、startMonth、可选 endMonth、foundingRulerId、startReason。Validator 校验月份、顺序、开创人物存在及姓氏匹配，但并非完整的任期/阶段关联证明；展示仍须核对真实即位、任期与角色。beginHouseEpoch 通常关闭旧阶段至新开始月份前一月；同月重复阶段可能同月结束。终结国家不会自动写入最后 epoch 的 endMonth。

因此最后阶段的显示终点来自明确 terminationMonth / extinctionYear，旧阶段保留 epoch 区间，并另显示真实交替记录月份。不回写 epoch，不从其界限推定某一天谁先谁后。同月有明确 rulerId 的个人事迹，只能归给其实际任期及阶段；无个人关联的国家事实按阶段月份归属，不补当前君主。

同姓可以是多段政治阶段；RESTORATION 是政治阶段起因，不是新血缘家族的证明。当前真实复国路径不保证创建新 epoch，原有 faction-restored 可属于同一段持续王统，模块不会补造 epoch。国家建立、正式建国与王统开端分别处理。

国家永久峰值不能可靠分摊给各段，本版全部省略；也不重新推算阶段疆域峰值、人口峰值、在国治理时间或宗族血缘。

## 证据与生成规则

- 只计算实际即位者：reignOrdinal、accessionYear 与 chronicle 俱全；heir/kin 候选不冒充已即位者。
- 成员按真实姓氏、任期交叠、开创人物及同月 ordinal 归属。旧君主在交替月结束、新君主同月即位时，不把旧君主计进新阶段。
- 同一真实君主若确实跨越记录中的复国阶段，可分别属于其实际参与阶段，不创建第二个人；阶段人数不能简单相加当国家总人数。
- 正式国家时期人数按任期与 stateFoundedMonth 交叠计算，建国前即位、建国时仍在位的人物正确计入。
- 只读取本国 indexed events，核对 actor/target、行政终结 SOURCE 角色、人物 ID 和任期。攻击方人物不能写成守方人物。
- 篡朝措辞要求 USURPATION 阶段并有真实 USURPER 开创人物或核验通过的 dynasty-usurped 事件。自然易姓不从姓氏变化反推暴力夺统。
- 代表性证据限最多3项，优先统一、篡朝、称帝、流亡、复国和终结，保留建国等起点。战争同组失都与失国不重复铺陈；几十年后的真正终结不并入失国月份。
- 史评最多3段：开创/人数、可核验年月人物地点、结局；史家曰关注传承与政治命运，不挪用国家永久峰值，也不重写国家或个人史评。
- 同月实际死亡与国家终结分别表述。政治终结不证明宗亲全部死亡；合邦和纳土使用行政终结/退位语义，不写战争覆灭。
- 历史国号使用事件月份 nameHistory。未结束王统为概览，当前流亡仍是持续承统，不提前盖棺。

## UI与性能

【天下势力→对应国家→王室】的王统信息附近新增【王统总评】，可折叠。单段显示简洁概览，多段默认最新，选择旧阶段按需查看；没有新主标签、大弹窗或宗谱节点样式。

一次仅挂载一个阶段正文，其他阶段仅为文本选项。缓存使用 WeakMap dynasty runtime 身份，加本国历史 revision、worldMonth、势力/身份及人物/epoch 摘要；hydration/reset 换 runtime 身份或 revision 后重算。同月人物/阶段变化也通过摘要失效。

成员归属 O(epoch数×本国君主数)，历史只做本国索引的一次遍历，按月二分定位阶段；已建立 ruler→phase 索引，避免每个事件再遍历所有君主。不扫描全世界事件，不逐帧计算、不持久化派生结果、不复制第二份事件数据库。
